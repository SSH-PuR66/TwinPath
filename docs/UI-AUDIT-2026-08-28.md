# UI audit — 2026-08-28

Why: Reddit called the TwinPath screenshots "AI slop". This is the list of
concrete tells found in the code and in `audit-shots/` + `docs/ui-shots/before-*`
before anything was changed. Baseline was green: `npm run audit`, `npm run build`,
`test:gallery` 8/8, `test:stripe-webhook` 6/6, `test:forgery-lab` 31/31,
`test:worker` 53/53. (`test/productionConfig.test.js` fails on `main` already —
it expects the production build to omit the control-plane URL that
`vite.config.js` now bakes in. Not touched by this work.)

## Tells, with where they live

1. **Glassmorphism on every surface.** `backdrop-filter: blur()` appears 40
   times (`styles.css` 29, `feature-components.css` 11): the header, `.glass-card`,
   `.hero`, the bottom nav (24px blur), modals. Cards are translucent over a
   blurred radial-gradient theme layer, so nothing has a real edge.
2. **Gradient haze as decoration.** `.hero` = accent→accent-2 diagonal gradient
   plus a blurred 12rem accent orb (`.hero::before { filter: blur(38px) }`).
   `.nav-indicator` = accent→accent-2 gradient. ThemeScene paints three radial
   accent blobs behind everything (`ThemeScene.jsx` `backgroundImage`). 135
   gradient/blur declarations across the three CSS files.
3. **Generic type.** `font-family: Inter, ui-sans-serif, …` and nothing else. No
   display face, no self-hosted font, weights sprayed across 400/600/650/700/
   750/760/780/800/850. 80+ distinct `font-size` literals (0.57rem … 1.05rem,
   9px … 16px) with the "scale" then hard-overridden to fixed px at the bottom of
   `design-system.css`.
4. **Eyebrow-on-everything.** Every card, pane and section opens with an
   accent-coloured tracked uppercase label (`.eyebrow`, `.tp-pane__head`), often
   twice in a row ("GUIDED" on the block *and* on each card; "CURRENT GOAL" on the
   pane head *and* the hero inside it). The device carries no information.
5. **Identical rounded cards, three-up.** 24× `border-radius:12px`, 19× `14px`,
   19× `999px`, 15× `15px/16px`, 10× `18px`, plus 13/17/20/22/23/26px. The
   summary grid is the "three feature cards with an icon in a tinted circle"
   pattern (`.summary-icon`, 40px accent-tinted rounded square) on Home and Money.
6. **Centered floating pill nav** with heavy shadow and blur on desktop too;
   at 1440px it floats in the middle of a 1180px column like a mobile mock.
7. **Motion without hierarchy.** CSS keyframes (`tp-rise`, `card-rise`, `row-in`,
   `disclosure-reveal`) all fire on mount with the same easing; framer-motion is
   only used for page fade and a nav indicator. No exit animations
   (`AnimatePresence` is never imported), no shared-element list→detail, no
   layout animation on re-sort, number ticker only on one balance. Skeleton
   shimmer is an infinite 1.4s loop.
8. **Two competing token layers.** `styles.css :root` defines colours + spacing
   1–5; `design-system.css` adds 6–9, a type scale and radii, then a second
   `:root` block at the bottom of the same file overwrites all of them with fixed
   px (radius-lg/xl collapse to 12px, space-7/8/9 collapse to 32px). Dark only;
   no semantic light set.
9. **Low-contrast secondary text.** `--subtle: #9a8b81` on `#14100e` ≈ 4.3:1 and it
   is used at 10–11px for pane heads and hints (`.tp-pane__head` 10px/600
   tracked uppercase in `--subtle`). Placeholder `#667086` on the near-black input
   is ≈ 3.2:1.
10. **Spacing off-scale.** Padding/gap literals like 0.35rem, 0.45rem, 0.55rem,
    0.72rem, 0.8rem, 0.9rem, 1.4rem, 11px, 13px sit next to the 4/8/12/16/24 scale.
11. **No imagery, no signature.** The only "visual" is the blurred theme haze. The
    product's own metaphor (two paths, a runway to late December) is drawn once as
    a bar strip and nowhere else.
12. **Copy tics.** "Scroll this pane, not the page", "One next move at a time",
    "Read the last 90 days first" as pane subtitles read as placeholder
    instructions rather than interface text.

Not found: emoji used as icons (all icons are already lucide), lorem text,
purple/blue gradients (the palette is warm — the problem is the haze, not the hue).

## What the overhaul keeps

- The theme catalog / ThemeScene feature and every theme's `--accent` override.
- MarketsDesk read-only rules (`test/marketsCatalog.test.js`): no write path, no
  fetch, literal fill classes. Only presentation changes there.
- Pane/rail layout (`.tp-shell`, `.tp-pane`, `usePaneOverflow`), disclosure
  persistence, flow engine, all data behaviour.
- The CSS class audit (`scripts/audit-css-classes.mjs`): every literal className
  added must exist in a stylesheet.
