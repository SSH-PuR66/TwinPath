# Cybersecurity Lab and Portfolio Tracker

A structured template pack for documenting authorized labs, evidence,
remediation steps and portfolio-ready summaries.

## Contents

- `lab-template.md` — the main lab documentation template
- `evidence-index.md` — an index for screenshots and artifacts
- `portfolio-checklist.md` — a checklist for publishing safe summaries

## Important

Only document work performed in environments you are explicitly
authorized to test. These templates are educational tools and do not
guarantee employment, certification or any specific outcome.
