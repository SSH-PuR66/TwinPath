# Portfolio Publishing Checklist

Use this before publishing any lab write-up publicly.

- [ ] Work was performed in an authorized environment
- [ ] Written authorization or lab terms are on file
- [ ] No real customer, employer or third-party data appears
- [ ] IP addresses, hostnames and credentials are redacted
- [ ] Screenshots are cropped and redacted
- [ ] The write-up explains objective, method and remediation
- [ ] No step-by-step exploit content targeting real systems
- [ ] Tone is factual; no exaggerated claims
- [ ] Spelling and formatting reviewed
- [ ] Final review complete
