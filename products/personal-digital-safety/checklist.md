# Personal Digital Safety Checklist

## Purpose

This educational checklist helps organize basic account and device
security. It does not guarantee complete security and does not replace
professional advice.

## 1. Protect the primary email account

- [ ] Use a unique password
- [ ] Enable multifactor authentication
- [ ] Save recovery codes in a protected offline location
- [ ] Review the recovery email
- [ ] Review the recovery phone number
- [ ] Remove old devices and sessions
- [ ] Review forwarding and filter rules
- [ ] Confirm security notifications are enabled

## 2. Use a password manager

- [ ] Choose a reputable password manager
- [ ] Create a unique master password
- [ ] Enable multifactor authentication
- [ ] Import accounts carefully
- [ ] Replace reused passwords
- [ ] Review emergency access settings
- [ ] Export or back up only through the provider's supported process
- [ ] Never send passwords through text or email

## 3. Secure financial accounts

- [ ] Use unique credentials
- [ ] Enable multifactor authentication
- [ ] Turn on transaction alerts
- [ ] Review linked devices
- [ ] Review linked applications
- [ ] Confirm recovery information
- [ ] Learn the institution's fraud-reporting process
- [ ] Never provide a one-time code to an unsolicited caller

## 4. Secure phones and computers

- [ ] Install current operating-system updates
- [ ] Use a strong device passcode
- [ ] Enable automatic screen locking
- [ ] Review application permissions
- [ ] Remove unused applications
- [ ] Enable device-location and remote-wipe features if appropriate
- [ ] Back up important data
- [ ] Verify the backup can be restored

## 5. Review social accounts

- [ ] Use unique passwords
- [ ] Enable multifactor authentication
- [ ] Review active sessions
- [ ] Remove unnecessary third-party applications
- [ ] Limit public personal information
- [ ] Review photo-location settings
- [ ] Review account-recovery options

## 6. Prepare for account recovery

- [ ] List critical accounts without recording passwords
- [ ] Record each provider's official recovery URL
- [ ] Store recovery codes securely
- [ ] Identify accounts that depend on the primary email
- [ ] Review recovery information every six months

## 7. Respond to suspicious activity

- [ ] Use the provider's official application or website
- [ ] Change exposed credentials from a trusted device
- [ ] End unknown sessions
- [ ] Preserve relevant messages and transaction details
- [ ] Contact the institution through an official number
- [ ] Report financial fraud promptly
- [ ] Do not pay unsolicited "recovery" services
