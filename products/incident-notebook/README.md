# Security Incident Notebook

A non-technical incident documentation pack for recording account,
device and business-security events.

## Contents

- `initial-response.md` — first-hours checklist and intake form
- `incident-timeline.md` — the main incident timeline worksheet
- `action-plan.md` — post-incident action plan

## Important

This is an educational documentation pack. It does not replace a
qualified incident-response, legal or forensic professional. Never
record passwords, recovery codes or full payment-card details in
these documents.
