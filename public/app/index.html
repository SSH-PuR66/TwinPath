TwinPath on your phone

Two ways. The first is the one to use every day.

1 · Add to Home Screen (recommended)

Full-screen app, auto-updates with every deploy, notifications, share-to-import. No signing, no expiry.

  1. Open this site in Safari.
  2. Tap Share, then Add to Home Screen, then Add.
Open TwinPath

2 · Install in LiveContainer

The native shell (arm64, portrait) that loads this same site inside LiveContainer. Tap the button on the phone that has LiveContainer installed.

Install with LiveContainer Download the .ipa instead If the button does nothing, LiveContainer is not installed on this phone, or it is an older build without the install link. Download the file, open it in Files, and choose LiveContainer.
Bundle com.twinpath.app · built unsigned on a macOS runner from the TwinPath repo · the shell points at this site, so it is always current.
